# CodeHeist

A platformer designed to teach programming made for my final not-final year project, or rather what could be finished within the time constraints. At present, this game only contains some of the core systems.

The final report can be found at: .

The present version of the game has been developed using **Godot 4.7.1**.

## Branches

| **main**       | Contains the most up-to-date code |
| -------------- | --------------------------------- |
| **submission** | Contains the project at time of submission, a.k.a. alpha-v1.0 |
| **gh-pages**   | Contains the GitHub pages deployment of the game used for testing |

Branch structure is subject to change.

**Warning:** the "docs" folder is not in a complete state, and is pending a complete rewrite. This was delayed to keep existing diagrams available whilst the final report was written. For details of the project's backend functionality view the report.
