# CodeHeist

A platformer designed to teach programming made for my final not-final year project, or rather what could be finished within the time constraints. At present, this game only contains some of the core systems.

This project uses **Godot verion 4.7.1** 

This source code is also available on github at [https://github.com/DrewanR/CodeHeist/tree/submission](https://github.com/DrewanR/CodeHeist/tree/submission) on the `submission` branch. The code on this branch will not be updated to preserve the project at time of submission.

## Viewing the game

It is recommended that you use the Godot editor (version 4.7.x) to view this game. This is because some files, mainly `.tscn` files, are not meant to be editted directly. `.gd` files can be opened in a text editor however, most text editors do not have native syntax highlighting for these scripts.

## Playing the game

There are three methods of playing/running the game. One online, one offline without compilation and one with compilation.

### Online **(Recommended)**

An online deployment has been made of the game using github pages. This allows you to play the game in you browser. The links for it are below, and within the deployments section of the final report.

Warning: some browsers, such as firefox on linux, can encounter performance issues when running the game, this is due to the engine and could not be patched.

| Version | Link |
| ------- | ---- |
| At time of submission    | [https://drewanr.github.io/CodeHeist/submission](https://drewanr.github.io/CodeHeist/submission) |
| User evaluation (unused) | [https://drewanr.github.io/CodeHeist/userEvaluation/play/](https://drewanr.github.io/CodeHeist/userEvaluation/play/) |
| Up to date\*             | [https://drewanr.github.io/CodeHeist/game](https://drewanr.github.io/CodeHeist/game) |

\*This may include changes made to the project after submission.

### Godot Editor

If you have the godot editor installed, with the project open, you can click the play icon in the top right hand corner (first icon of seven) to play a non-compiled version of the game.

You may have to change some settings on the embedded player for the screen to scale correctly.

### Exported

You may also play an exported version of the game.

You can export the game under "project > export..." youself. This is not recommended as it requires you to install export templates and can be finicky.

Alternatively, you can download an already exportted version of the project from [https://github.com/DrewanR/CodeHeist/releases/tag/alpha-v1.0](https://github.com/DrewanR/CodeHeist/releases/tag/alpha-v1.0). This also is not recommended unless you are expiriencing issues with the browser versions and want to avoid installing Godot on your machine.
